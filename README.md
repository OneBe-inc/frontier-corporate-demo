# ワンビー工業 / ONEBE INDUSTRIES

架空の精密金属加工会社の企業サイト。白・濃紺を基調に、工場の仕事、加工技術、部門間の工程を紹介する独自デザインです。

- 公開: https://onebe-inc.github.io/frontier-corporate-demo/
- 工程ページ: https://onebe-inc.github.io/frontier-corporate-demo/chart/
- GitHub Pages: main / root
- HTML・CSS・JavaScriptのみ。ビルド依存なし。
- 画像は本制作向けに生成したラスター画像。既存番組の写真・ロゴ・ソースコードは使用していません。
- 社名・事業・採用情報は架空の設定。実在する同名企業とは無関係。問い合わせ送信・個人情報保存は行いません。
- 検索インデックスを抑制するため noindex,nofollow を指定。アクセス制限ではありません。

## 操作
サービス切り替えはマウス・キーボード矢印で操作できます。工程は部門グループで絞り込みでき、URLの step パラメータから工程を直接表示します。モーダルは Escape または閉じるボタンで終了します。
